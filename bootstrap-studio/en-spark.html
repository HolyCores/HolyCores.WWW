SPARK MODULES

From embedded module, to edge server.

Three formats span sensor endpoints, compact hosts and multi-camera vision systems. Parameters below are product planning targets.
EMBEDDED / 15 W CLASS

SPARK S20

A compact M.2 module for low-power local inference in robots, cameras and intelligent terminals.

COMPACT / 35 W CLASS

SPARK S40

A low-profile PCIe module for embedded servers, industrial vision and multi-model pipelines.

RUGGED / 75 W CLASS

SPARK S80

An actively cooled, industrial-I/O edge card designed for sustained multi-camera and robotics-server workloads.
